# kgviz — agent guide

This repo has **two parallel layers**. Do not conflate them.

```
repo/
├── viewer/          ← browser HTML component (React/Three.js) — owns rendering
├── kgviz/           ← Python wrapper — owns data prep + embedding
├── example/         ← Streamlit demo app
├── AGENTS.md        ← you are here
└── pyproject.toml
```

## Architecture

```
┌─────────────────────────────────────────────────────────────┐
│  Python host (Jupyter / Streamlit / Gradio / Dash / script) │
└──────────────────────────┬──────────────────────────────────┘
                           │
                    kgviz/ (Python)
                    ├── Graph3D figure
                    ├── _normalize.py   — nodes/edges/NetworkX
                    ├── _html.py        — to_html() embed generator
                    ├── _assets.py      — locate viewer JS bundle
                    ├── _streamlit.py   — optional Streamlit bridge
                    └── integrations.py — Gradio/Dash/marimo helpers
                           │
                     JSON config
                           │
                    viewer/ (browser)
                    ├── KGVizView.tsx   — 3D graph renderer
                    ├── index.tsx       — standalone vs Streamlit bootstrap
                    └── build/assets/kgviz.js
```

**Rule:** visualization features belong in `viewer/`. Python only prepares data and embeds HTML.

## Python package (`kgviz/`)

| Module | Responsibility |
|---|---|
| `figure.py` | `Graph3D` class, `kgviz()` entry point, `_repr_html_`, `show()` |
| `_normalize.py` | DataFrame/list/NetworkX → `{nodes, edges}` |
| `_html.py` | `Graph3D.to_html()` — inlines `window.__KGVIZ_CONFIG__` + JS bundle |
| `_assets.py` | Finds `viewer/build/` or `kgviz/_viewer/build/` |
| `_streamlit.py` | `declare_component("kgviz", ...)` — bidirectional click events |
| `integrations.py` | Thin adapters for Streamlit, Gradio, Dash, marimo |

### Public API

```python
from kgviz import Graph3D, kgviz

fig = Graph3D(nodes=n, edges=e)
fig.show()       # Jupyter or browser
fig.to_html()    # embed anywhere

# In Streamlit — auto-renders:
click = kgviz(nodes=n, edges=e, key="g")
```

### Framework embedding

| Framework | How |
|---|---|
| Jupyter | `fig` in cell (uses `_repr_html_`) |
| Streamlit | `kgviz(...)` or `integrations.streamlit_chart(fig)` |
| Gradio | `gr.HTML(integrations.gradio_html(fig))` |
| Dash | `integrations.dash_iframe(fig)` |
| Flask/FastAPI | `return fig.to_html()` |

Streamlit is an **optional extra**: `pip install "kgviz[streamlit]"`

## Browser viewer (`viewer/`)

See `viewer/README.md` for full detail.

| File | Role |
|---|---|
| `src/KGVizView.tsx` | All 3D rendering, toolbar, search, export PNG |
| `src/index.tsx` | Boots standalone if `window.__KGVIZ_CONFIG__` is set; else Streamlit mode |
| `src/types.ts` | Config contract — keep in sync with Python `Graph3D.to_dict()` |

### Config injection

Standalone mode (generated by Python `_html.py`):

```html
<script>window.__KGVIZ_CONFIG__ = { graph_data, node_color, ... };</script>
<script type="module">/* inlined kgviz.js */</script>
<div id="root"></div>
```

Streamlit mode: config arrives via `streamlit-component-lib`; click events go back via `Streamlit.setComponentValue`.

## Build workflow

```bash
# 1. Build viewer (required before Python packaging or Streamlit release mode)
cd viewer && npm install && npm run build

# 2. Install Python package
pip install -e ".[dev]"

# 3. Run demo
streamlit run example/app.py
```

`npm run build` writes to:
- `viewer/build/` — primary output
- `kgviz/_viewer/build/` — copy for Python wheel / Streamlit component path

## Where to make changes

| Task | Location |
|---|---|
| New visual feature (glow, labels, toolbar) | `viewer/src/KGVizView.tsx` |
| New styling option | `viewer/src/types.ts` + `kgviz/figure.py` + `KGVizView.tsx` |
| New data input format | `kgviz/_normalize.py` |
| New framework adapter | `kgviz/integrations.py` |
| HTML embed format | `kgviz/_html.py` |
| Demo / examples | `example/` |

## Do not

- Put Three.js or canvas rendering logic in Python
- Import Streamlit in core `kgviz/` modules (only `_streamlit.py`)
- Edit `kgviz/_viewer/build/` by hand — it is generated by `viewer/npm run build`
- Break the `ComponentArgs` contract without updating both `types.ts` and `figure.py`
